# Tax Strategy Simulator

A browser-based tax strategy simulator that helps users compare different tax scenarios and optimize their tax planning.

## Features

- **100% Browser-Based**: No server required - runs entirely in your web browser
- **Mobile-Friendly**: Optimized for iPad and other mobile devices
- **Privacy-First**: All calculations happen locally - no data sent to servers
- **Vanilla JavaScript**: No frameworks or dependencies required

## Quick Start

1. Clone this repository
2. Open `index.html` in your web browser
3. Start exploring tax strategies!

## Files

- `index.html` - Main application file
- `styles.css` - Styling and responsive design
- `calculator.js` - Tax calculation logic
- `README.md` - This file

## Browser Compatibility

- Chrome/Edge (recommended)
